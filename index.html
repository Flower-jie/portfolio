    04 / A LITTLE CONTEXT

    你可能还想知道。

    关于项目、源码，
    以及这份作品集的边界。

    这些项目都是从零原创的吗？+

    不是。天机学堂、黑马点评和苍穹外卖是课程学习与实践项目，对外提供公开脱敏版，不代表商业交付或工作经历。LearnHub AI 是独立实现的知识库学习项目；本作品集用于整理与分享这些实践。

    AI 学习助手需要配置 API 吗？+

    本地知识检索不需要模型 API。要使用模型生成回答，需要自行配置兼容的模型服务及相关密钥，费用和可用性由所选服务决定。默认词项哈希检索与可选语义向量明确区分；没有足够证据时不会生成答案。模型配置说明见本地应用的连接页面。

    可以直接在线体验后端项目吗？+

    本网站是静态作品集，没有部署这些项目的在线后端演示。项目卡片链接均为源码入口；本地运行需要按对应仓库说明准备 Java、数据库及其他依赖。不要在公开仓库提交自己的密钥或真实业务数据。

    GitHub 和 Gitee 怎么选择？+

    每张卡片提供两个平台的对应仓库入口，可按访问习惯选择。课程项目在 Gitee 使用带 -public 的公开脱敏版仓库名。两端内容及更新时间请以各仓库提交记录为准，不承诺实时自动镜像。

    这份项目集会如何继续更新？+

    项目名称、分类、技术、状态及双平台地址集中维护在 projects.json。新增项目只需添加一条数据，页面会自动生成卡片、分类数量和搜索内容，无需手动修改页面布局。
